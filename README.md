# Student-Helpdesk-System
A beginner level Java console-based Student Helpdesk and Support Ticket Management System using OOP concepts.

## About the Project
The Student Helpdesk System is a Java-based console application designed to manage student support tickets. It allows users to create, view, search, update, and track support issues through a menu-driven interface.

## Features
- Create support tickets
- View all available tickets
- Search tickets using Ticket ID
- Update ticket details
- Manage ticket status
- Handle ticket categories and priorities
- Input validation and exception handling

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Java Enums
- Exception Handling

## Project Structure
- `Main.java` – Application entry point and console menu
- `User.java` – Stores student information
- `Ticket.java` – Manages ticket details and status
- `HelpdeskService.java` – Handles ticket management operations
- `Category.java` – Defines ticket categories
- `Priority.java` – Defines ticket priorities
- `TicketStatus.java` – Defines ticket statuses

## How to Run
1. Clone the repository.
2. Open the project in your preferred Java IDE.
3. Compile the Java files.
4. Run `Main.java`.

## Learning Objectives
This project was developed to practice Java fundamentals, object-oriented programming, class interaction, collections, and exception handling.
